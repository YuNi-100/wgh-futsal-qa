# 근거 데이터 확인

이 폴더의 사실표는 기존 서버의 `futsal_facts.csv` 원본을 복원한 파일이 아닙니다. 2026-11-09에 PC에 보관된 조회 결과 CSV를 바탕으로 재구성했습니다. 사실ID도 이 파일 안에서 새로 부여했으므로 과거 답변의 사실ID와 비교하면 안 됩니다.

| 파일 | 내용 | 확보한 자료 |
| --- | --- | --- |
| `matches_snapshot.csv` | 경기 10건의 날짜, 팀, 점수, 장소 등 | 다운로드 폴더의 `풋살데이터추가분석/wgh-analysis.csv` 사본 |
| `videos_snapshot.csv` | 영상 목록과 매치 연결 정보 | 다운로드 폴더의 `풋살대시보드/wgh-analysis.csv` 사본 |
| `futsal_facts.csv` | 위 사본에서 만든 검색용 문장, 사실ID와 출처 | 경기별 결과·장소, 친선경기 영상 연결 집계 |

사본에는 추출 시각이 기록돼 있지 않습니다. README의 2026-11-06 확인 수치와 대조할 수 있으나 현재 운영 DB의 최신 상태를 보장하지 않습니다. 원본의 장소명과 빈 리그 값은 그대로 보존했습니다. 선수별 출전·득점 기록이나 규정 원문은 포함하지 않았습니다. 예제 질문 중 2026-10-07 YDP전 득점 선수는 이 자료만으로 확인할 수 없습니다.

## 실제 호출 흐름

`app.py`의 `answer()`에서 `evidence=True` → `rag.ask()` → `build_store()` → `load_facts()` 순서로 호출합니다. `load_facts()`는 **rag.py에 정의**되어 있으며 일반 운영 DB 집계에서는 호출하지 않습니다. 벡터 저장소가 캐시돼 있으면 같은 키와 같은 CSV 내용으로 다시 로딩하지 않습니다.

`keep_default_na=False`는 CSV의 빈 문자열이나 `NA` 등을 자동으로 `NaN`으로 바꾸지 않게 합니다. `사실ID`, `내용`, `출처`는 검색 문서 구성에 쓰이고, `기준`은 검토용 설명입니다.

일반 질문과 조건 조회는 `read_wgh_db.py`를 통해 PostgreSQL을 조회합니다. 이 CSV들은 운영 DB의 대체 데이터가 아닙니다. 근거 확인을 실행하려면 OpenAI 키가 필요하며 현재 API 진입 조건상 DB 연결 변수와 인증 토큰도 필요합니다.
